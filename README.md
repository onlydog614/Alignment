# 視覺對位除錯工具（Vision Alignment Debugger）

用來檢查視覺對位計算是否正確的網頁工具：輸入各相機的校正、量測值與平台設定，計算平台修正量與各軸指令，並以圖形呈現誤差與修正後預測。

## 使用方式

直接用瀏覽器開啟 `index.html`（不需安裝、不需網路）。

1. 點「載入範例」看雙相機 XXY 平台的範例。
2. 選平台種類，設定旋轉中心；展開「軸設定」依機構圖修改致動點位置與方向。
3. 用「＋／−」調整相機數量，輸入每台的校正、目前量測與目標像素。
4. 右側看修正量、各軸指令與警告；中間圖形的誤差向量會依「誤差放大」倍率繪製。
5. 「模擬迭代」可加入雜訊或旋轉中心偏差，觀察是否收斂。

## 檔案

| 路徑 | 內容 |
|---|---|
| `index.html` | 主頁面 |
| `js/geometry.js` | 校正轉換、剛體擬合、軸指令計算（不依賴 DOM） |
| `js/platforms.js` | 平台種類預設 |
| `js/app.js` | 介面、繪圖、模擬 |
| `docs/vision-alignment-notes.md` | 視覺對位知識整理與除錯清單（含 Omron FH 對應） |
| `docs/ROADMAP.md` | 分段開發計畫 |
