# 分段開發計畫

不考慮開發時程，每一階段都可獨立使用、驗收後再進下一階段。

## 第 1 階段 — 初版頁面（v0.1，已完成）

- [x] 純前端單頁，直接雙擊 `index.html` 即可使用（不需安裝、不需網路，適合產線電腦）
- [x] 相機數量可增減（1–16 台），每台各自設定解析度與校正
- [x] 校正輸入：簡易模式（像素當量、角度、反向、中心位置）／仿射矩陣 A–F
- [x] 平台種類：XYθ、θXY、XXY、XYY、UVW 三軸、UVW 四軸、自訂（通用致動點模型）
- [x] 最小平方剛體擬合 → ΔX、ΔY、Δθ → 各軸指令
- [x] 診斷：擬合殘差、標記間距比（伸縮）、校正手性、正交性、公差判定
- [x] 視覺化：視野、目標／目前／修正後預測、誤差向量放大、旋轉中心、軸方向
- [x] 模擬迭代：量測雜訊、機構比例誤差、旋轉中心偏差，觀察收斂
- [x] 設定匯出／匯入（JSON）、瀏覽器自動保存
- [x] 知識整理文件 `docs/vision-alignment-notes.md`

## 第 2 階段 — 校正工具

- [ ] N 點（9 點）校正計算：輸入像素／平台座標對 → 求 A–F，顯示每點殘差
- [ ] 旋轉中心求取：多角度量測 → 擬合圓心與半徑，顯示擬合誤差
- [ ] 最大誤差最小化（minimax）擬合選項，與最小平方法並列比較
- [ ] 每台相機的像素視圖（影像座標下的目前／目標點）
- [ ] 誤差歸因提示：依迭代紀錄型態推測（方向反、比例錯、旋轉中心錯、雜訊極限）

## 第 3 階段 — Omron FH 資料串接

- [ ] 依你實際的 FH 流程（場景、處理項目、輸出格式）建立對應表
- [ ] 貼上／匯入 FH 輸出字串或 CSV 記錄 → 自動填入量測值
- [ ] 本機橋接程式（Node.js 或 Python）：TCP 無協定 ↔ WebSocket，即時接收 FH 結果
- [ ] 與 FH 計算的軸移動量自動比對，標示差異

## 第 4 階段 — 統計與追蹤

- [ ] 多筆記錄的趨勢圖（誤差、修正量、迭代次數）
- [ ] 重複性（同一工件多次量測）與 3σ 統計
- [ ] 溫漂、時間相關分析
- [ ] 報表輸出

## 第 5 階段 — 進階機構

- [ ] 相機隨動（相機裝在軸上）
- [ ] 上下視相機（物件對物件、貼合 offset）
- [ ] 大角度下 UVW 精確運動學
- [ ] 多平台／多工位配方管理
