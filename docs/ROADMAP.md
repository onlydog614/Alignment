# 分段開發計畫

不考慮開發時程，每一階段都可獨立使用、驗收後再進下一階段。

## 第 1 階段 — 初版頁面（v0.1，已完成）

- [x] 純前端單頁，直接雙擊 `index.html` 即可使用（不需安裝、不需網路，適合產線電腦）
- [x] 相機數量可增減（1–16 台），每台各自設定解析度與校正
- [x] 校正輸入：簡易模式（像素當量、角度、反向、中心位置）／仿射矩陣 A–F
- [x] 平台種類：XYθ、θXY、XXY、XYY、UVW 三軸、UVW 四軸、自訂（通用致動點模型）
- [x] 最小平方剛體擬合 → ΔX、ΔY、Δθ → 各軸指令
- [x] 診斷：擬合殘差、標記間距比（伸縮）、校正手性、正交性、公差判定
- [x] 視覺化：視野、目標／目前／修正後預測、誤差向量放大、旋轉中心、軸方向
- [x] 模擬迭代：量測雜訊、機構比例誤差、旋轉中心偏差，觀察收斂
- [x] 設定匯出／匯入（JSON）、瀏覽器自動保存
- [x] 知識整理文件 `docs/vision-alignment-notes.md`

## 第 2 階段 — 校正工具與模擬（v0.2，已完成）

- [x] 資料模型改為「相機」與「拍照點」分開：同一相機可拍多個 mark、同一 mark 可在不同步驟用不同相機拍
- [x] XY 線馬拍照位置（線馬移動平台或移動相機）
- [x] 多步驟流程（粗對位 → 精對位），各步驟公差、最多次數、Gain、最少移動次數
- [x] 光學計算：感光元件＋一般鏡頭（焦距、工作距離）／遠心鏡頭（倍率）→ 像素當量、視野、Z 對倍率的影響
- [x] N 點（9 點）校正計算：求 A–F，顯示每點殘差、正交性、與目前設定比較，可直接套用
- [x] 旋轉中心求取：圓擬合＋共變異數不確定度、θ 比例檢查、小視野相機的線馬跟隨模式
- [x] 最大誤差最小化（minimax）擬合選項
- [x] 每個拍照點的影像視圖
- [x] 誤差來源推測（比例、旋轉中心、雜訊極限、振盪、發散），依雜訊與公差過濾誤判
- [x] 情境模擬器（Monte-Carlo）：真實世界誤差模型、教導目標、成功率／真實誤差／收斂圖／散佈圖／參數掃描
- [x] FPC 四 mark＋XYθ＋線馬＋粗/精相機範例與模擬測試報告（`docs/simulation-report.md`）
- [x] 單元測試與 GitHub Pages 自動部署

## 第 2.5 階段 — 校正手順（v0.3，已完成）

- [x] 「校正手順」分頁：依平台、線馬、Z 軸、每台相機安裝方式（往下看／往上看／裝在線馬上）、對位方式產生校正順序
- [x] 每個步驟的圖解（流程圖、九點、旋轉中心、上下視連結 B_off、線馬連結、多相機連結、對焦、教導、實放驗證）
- [x] 自動計算建議參數：九點間距、旋轉角度與方法（直接轉／線馬跟隨／Mark 靠近中心）、預估旋轉中心精度 vs 需求
- [x] 旋轉中心改用「已知指令角度」擬合（精度 ≈ 雜訊 ÷ 角度，與半徑無關），幾何圓擬合保留作交叉檢查
- [x] 列印／存成 PDF

## 第 2.6 階段 — 圖形化設定（v0.4，已完成）

- [x] 「圖形設定」分頁（預設首頁）：俯視配置圖，可點選與拖曳平台、工件、相機、旋轉中心
- [x] 圖卡選擇：平台種類（自動繪製軸配置圖示）、鏡頭預設、相機安裝方式、Mark 排列、線馬模式
- [x] 流程管線：每步驟勾選相機、公差、次數；顯示每步驟幾點直接拍／幾點靠線馬
- [x] 依配置自動產生拍照點（相機看得到就直接拍，看不到且有線馬時自動計算線馬位置）
- [x] 總覽檢查清單、一鍵模擬工件偏移

## 第 2.7 階段 — 多平台（v0.5，已完成）

- [x] 「多平台」分頁：共同基板座標、多平台分區（負責欄）、各平台可見 Mark、θ 來源（Mark／機構）、軸比例
- [x] 解析式誤差傳遞到每片 Tile（Mark 辨識、θ×距離、軸比例、熱膨脹、貼附），交界相對誤差
- [x] 誤差熱圖（各方案同一色階）、各欄長條、三種 Mark 配置比較、Monte-Carlo 驗證（與解析式差 < 2%）
- [x] 兩平台座標轉換的實測輸入：共同點貼上 → 剛體／相似／仿射擬合、殘差與錯點警示、模型建議、轉換不確定度、批次換算（A→B／B→A）、模擬資料

## 第 3 階段 — Omron FH 資料串接

- [ ] 線馬實際位置（光學尺回授）輸入，與指令位置比較
- [ ] 依你實際的 FH 流程（場景、處理項目、輸出格式）建立對應表
- [ ] 貼上／匯入 FH 輸出字串或 CSV 記錄 → 自動填入量測值
- [ ] 本機橋接程式（Node.js 或 Python）：TCP 無協定 ↔ WebSocket，即時接收 FH 結果
- [ ] 與 FH 計算的軸移動量自動比對，標示差異

## 第 4 階段 — 統計與追蹤

- [ ] 多筆記錄的趨勢圖（誤差、修正量、迭代次數）
- [ ] 重複性（同一工件多次量測）與 3σ 統計
- [ ] 溫漂、時間相關分析
- [ ] 報表輸出

## 第 5 階段 — 進階機構

- [ ] 相機裝在 XYθ 軸上（目前支援的是相機裝在線馬上）
- [ ] 上下視相機（物件對物件、貼合 offset）
- [ ] 工件伸縮的處理策略（尺度補償、以某邊為主）
- [ ] 大角度下 UVW 精確運動學
- [ ] 多工位配方管理（每個平台一份完整的對位設定）
