# 視覺對位顧問陣容（Configurable Council 用）

在新工作階段執行 `council-setup` 時使用這份陣容。

| 顧問 | 負責看什麼 |
|---|---|
| 校正工程師 | 像素轉 mm 的 A–F 參數、9 點校正殘差、v 軸方向和鏡像 |
| 運動控制工程師 | XYθ／UVW 的軸指令換算、旋轉中心、θ 比例、重複定位 |
| 光學／影像工程師 | 鏡頭倍率、遠心與否、景深、Z 高度變化、找特徵穩不穩定 |
| 量測與統計專家 | 不確定度、Monte-Carlo 結果判讀、公差夠不夠 |
| 現場應用工程師（Omron FH） | 實機設定、常見現場錯誤、手冊上的限制 |
| 魔鬼代言人 | 專門挑其他人結論的漏洞 |

## 使用建議

1. 先用本工具或 `node tests/run.js`、`tests/scenario-report.js` 取得實際數據。
2. 再把數據（殘差、收斂紀錄、誤差來源推測）交給 Council 判讀與辯論。
3. Council 不會執行程式或截圖，數值驗證仍以工具計算為準。
